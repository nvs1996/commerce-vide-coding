# Commerce Vibe Coding

Node.js + Express + EJS + SQLite (`node:sqlite`, Node 22.13+). Theme: AdminLTE 4 (npm).

    npm install
    npm start        # http://localhost:3000

| Area  | URL                     | Login              |
|-------|-------------------------|--------------------|
| Shop  | http://localhost:3000/  | demo / demo123     |
| Admin | http://localhost:3000/admin | admin / admin123 |

Database file `data.db` is created and seeded on first run (delete it to reset).
